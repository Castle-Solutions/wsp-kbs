# wsp-kbs

Bases de conocimiento y recursos de los agentes de WhatsApp (Kapso), organizados por cliente.

```
<cliente>/
  data/      CSV con datos de referencia
  docs/      documentos y FAQ
  assets/    imágenes y archivos que los agentes envían (URLs públicas)
```

## Clientes
- `grounded-labs/`: Grounded Labs (agente Terra)
